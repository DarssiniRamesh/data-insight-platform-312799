# Frontend React

## Overview
Frontend application for the Data Insight Platform, providing user interface for uploading files, viewing datasets, and visualizing data with interactive charts.

## Getting Started

### Installation
```bash
npm install
```

### Running the Application
```bash
npm start
```

The application will start on port 3000 and automatically open in your default browser.

### Available Scripts

- `npm start` - Runs the app in development mode
- `npm build` - Builds the app for production
- `npm test` - Runs the test suite

## Features
- User authentication
- File upload interface
- Data processing dashboard
- Interactive charts and visualization
- Dataset explorer

## Theme
The application uses the "Pure White" theme with:
- Primary color: #374151
- Success color: #10B981
- Background: #f9fafb
- Modern, minimalist design

## Port
The application runs on port 3000 by default.
